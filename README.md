# 驼峰调车 — 平面调车一体化优化平台

北京市大学生交通科技大赛（第十四届）项目。把「驼峰调车」与「平面调车」两个自成一体的模块串成一条完整链路。

## 结构

| 文件 / 目录 | 说明 |
| --- | --- |
| `index.html` | 封面 / 导航 + 衔接说明 |
| `hump.html` | **第一部分** · 驼峰调车（峰高/纵断面多目标优化 + 解体溜放分配） |
| `flat/` | **第二部分** · 平面调车（SAN 弧模型 + A*，同学 FD4 平台） |

## 衔接流程

1. 第一部分「解体与溜放分配」页录入待解体车列，按去向分配分类线。
2. 点「一键传送到平面调车」→ 数据（paper 模式初始状态 + 去向顺序）写入浏览器本地存储并跳转。
3. 第二部分点「从驼峰平台导入」→ 自动填充车辆 / 股道 / 去向顺序 → 「开始求解」。

衔接采用平面调车平台的**论文模式**（`goalMode:'paper'` + `destinationOrder`），
只需 `initial` 初始状态，由算法按去向顺序自动集结成出发车列，无需指定精确终态。

## 部署

纯静态网站，直接托管到 GitHub Pages / Nginx / Apache 即可。

```bash
# 本地预览
python -m http.server 8000
# 打开 http://localhost:8000
```

浏览器内置模式在 Web Worker 中运行，无需后端。如需 Gurobi 模式，另行部署
`flat/gurobi-backend`（见其 README，需有效 Gurobi 许可证）。
